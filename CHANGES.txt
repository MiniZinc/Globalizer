======================
# Globalizer Changelog #
======================


Version 0.1.6.0
=============

Changes:
 - Initial pass searches for redundant submodels (can be replaced by
   "constraint true") These submodels are not explored in the full
   (second) Globalizer pass
 - Redundant submodels are now presented to the user as such (previously
   reported as "true")
 - NUMGROUPS statistic is updated to show the real number of groups
   left after removing the redundant submodels - Added ability to select
   which parts of a model should be included/excluded using paths (Text
   spans)

Bug fixes:
 - Don't create 'forall' constraints with only a single element:
   'constraint forall([C])' should be represented as 'constraint C'
 - Allow for trailing comma in arguments of Calls: previously "C(a,)" could
   not be parsed
